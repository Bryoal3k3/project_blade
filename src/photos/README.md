# Bey photos

Drop a photo here named after the Bey's `id` from `src/data/beys.json`, and the app shows it instead of the drawn stand-in. No code changes needed.

- `dran-sword.jpg`, `wizard-rod.png`, `phoenix-wing.webp` and so on.
- Square photos on a plain background look best. Keep each one under about 1 MB.
- A photo taken from straight above can spin like the real top: set `"photoSpins": true` on that Bey in `beys.json`.
